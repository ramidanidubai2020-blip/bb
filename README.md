# A Little Hello

A simple greeting page for someone special, followed by date polls, a planner, and a final farewell page. The greeting says, "Indet nesh, tegadalit?" The date poll asks, "Can we go out for a little date?" with Yes and No choices. A Yes response opens the planner for date, time, place, and a note, then the meeting poll asks "Yet ingenagn?". The final page says "Thanks for your time. Luv ya."

## Run

Open `index.html` in a web browser. Use **I have a question for you** to go to the date poll. A Yes response offers the planner, which links to the meeting poll and then the photo page. No install, build step, or server is needed.

Choose a different background on each page: first, second, third, fourth, and fifth photo. Each page stores its own photo in this browser, along with poll answers and date details; nothing is uploaded or shared online.

## Customize

Edit the greeting copy in `index.html`; adjust photo handling in `app.js` and colors and layout in `styles.css`.
